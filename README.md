# Origin
Procedural world game based on raycast rendering and sparse voxel octree technologies with using Vulkan API.

## Dependencies
- [Vulkan SDK 1.4.357.1](https://vulkan.lunarg.com)
- [SDL 2.32.2](https://www.libsdl.org)
- [FreeType 2.14.3](https://www.freetype.org)
- [Bullet 3.25](https://github.com/bulletphysics/bullet3)
- [Qt 6.11.0](https://www.qt.io)

## Status
Initial development stage.
